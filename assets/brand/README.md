# Teagram brand kit

## Primary mark

<img src="png/t-primary-256.png" width="128" alt="Teagram primary mark">

The **T speech bubble**: the letter T whose stem ends in a speech-bubble tail. White on a tea-green gradient (`#3FD49A` to `#0E8A63`).

Use it for the app icon, the GitHub avatar, favicons and anywhere Teagram needs a single mark.

## Files

- `svg/`: masters, 1024 x 1024 with the rounded-square tile built in.
- `png/<name>-<size>.png`: 16, 32, 64, 128, 256, 512 and 1024 px.

## Rules

- Keep the tile shape and the tail pointing down-left. Don't rotate, outline or recolour the T outside these colourways.
- Leave clear space around the tile of at least a quarter of its width.
- Teagram is not affiliated with Telegram: never pair these marks with Telegram's logo, paper plane or blue circle.
